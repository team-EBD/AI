# AI 출력 검증 실험 — 2026-10-25

## 목적과 근거

기획심의(2026-06-04), 중간점검(2026-08-24), 멘토 대화에서 제기된 음식량·영양값·제품 변형 오류와 검증 근거 부족을 코드 수준에서 조사했다. 원문은 작업폴더 `report/`에 있으며, 대화 원문·개인정보·이미지·키는 이 저장소에 복사하지 않았다.

중간평가의 사진 칼로리 오차율 29.4%는 당시 별도 사진 평가 결과다. 이번 실험은 **합성 모델 출력의 계약 충족 여부**를 측정한다. 이번 수치를 메뉴 인식 정확도, 실측 칼로리 오차 개선, 실제 실패율 감소, 리텐션 향상으로 해석할 수 없다.

## 실험 설계

- 기준 코드: `origin/main`의 `9ce6e9ee029d5891f92b2488672404d861c37ec1`.
- 최종 동일 59케이스를 기준 코드와 수정 코드에 실행했다. 46건은 의도적으로 잘못된 출력/행/이유를 넣는 시험이고 13건은 정상 대조다.
- `--baseline-ref`는 해당 Git 버전의 `ai-server/app`만 임시 폴더에 추출한다. `.env`, 운영 데이터 및 Git 메타데이터를 추출하지 않는다.
- 모델 생성과 검색은 stub으로 대체한다. 운영 DB 쿼리, 실제 모델 API 호출 모두 0회다.
- 임의 무작위 표본이나 독립적인 정답 데이터셋이 아니다. 운영 발생 빈도, 통계적 일반화, 신뢰구간, 실제 서비스 효과를 산출하지 않는다.
- 결과 JSON에 실행 시각, Python/패키지 버전, 기준 SHA, 실제 app 소스의 SHA-256, 개별 케이스 결과를 기록한다. `after.json`의 `base_revision`은 변경을 얹은 기준 커밋이며 실제 변경 코드 식별은 `app_source_sha256`으로 한다.

기존 테스트 중 영양 검증에서 부수적으로 고정하던 후보 순서를 집합 비교로 바꾸었고, 상한 테스트의 5개 복제 항목은 서로 다른 대체 이름으로 교체했다. 응답 로깅 테스트의 텍스트 구조 오류 예상값도 의도된 `invalid_response`로 수정했다. 상한, 음식 보존, 민감한 응답 로그 마스킹의 검증은 유지한다.

## 동작 변경과 운영 관찰 항목

응답 필드·인증 계약·DB 읽기 전용 원칙을 유지했다. 실패 enum을 추가하지 않았다. 잘못된 텍스트 출력은 `not_food` 대신 기존 `invalid_response`가 된다. 이 변화 전후의 사유 분포를 비교할 때 분류 변경을 고려해야 한다. FE는 수정하지 않는다.

분석·텍스트·제품검색의 프롬프트 상수는 변경하지 않았다. 추천 프롬프트에 들어가는 생성 힌트 중 초과 칼로리에 대한 문장만 `오늘 남은 목표 칼로리를 초과해요...` 또는 목표 도달 안내로 변경했다. 이를 포함한 내용은 단위 테스트로 확인했으며 실제 모델이 이유를 얼마나 잘 생성하는지는 측정하지 않았다.

검색어만 반환한 grounding 응답은 이제 `label=None`이므로 검색 영양표 적용률이 낮아질 수 있다. 이때 기존 DB/모델 추정 경로를 사용하며 추정 정확도가 보장되는 것은 아니다. URL 존재는 페이지에 정확한 제품 영양표가 있다는 증명이 아니다. 제로/무가당/라이트 검사도 **입력에 명시한 변형이 결과명에 나타나는지**만 확인한다. 일반 제품이 제로 제품으로 바뀌는 반대 방향, 모든 맛·브랜드·국가별 상품의 동일성은 보장하지 않는다. 전체 상품 동일성은 별도 정답 제품셋으로 평가해야 한다.

영양 기준은 고체 100g 또는 액체 100ml다. 액체 밀도를 모르므로 탄단지 합계가 100을 넘었다는 이유만으로 제거하지 않는다. 이 오탐을 막기 위해 100ml당 탄수화물 110g 등의 농축액 정상 대조를 포함했다. 4/4/9 열량 일치도 당알코올·식이섬유·알코올 등 때문에 이번에 강제하지 않았다.

의학 표현 필터는 일부 무해한 문구도 고정 생활식단 문구로 대체할 수 있고, 우회 표현을 놓칠 수 있다. 식품 알레르기·질환별 안전성 판정 도구나 법적 검토를 대신하지 않는다. 실제 출력 표본으로 오탐/누락을 평가해야 한다.

배포 후 비교할 항목: `invalid_response`/`not_food`/provider 오류, 검색 라벨 적용률, 동일 조건의 후보수, 분석 지연 p50/p95, 수정 후 저장률. 사용자 효과·실측 영양 정확도·자동보정 감소는 **결과 확인후 추가 혹은 수정필요**. 실측 평가 계획은 [real_world_evaluation.md](real_world_evaluation.md)에 있다.
